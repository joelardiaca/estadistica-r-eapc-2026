Sessió 3 · Explicació complementària

NotaQuè hi trobareu?

El t-test i l’ANOVA tenen un supòsit: que la variable numèrica sigui (aproximadament) normal dins de cada grup. Aquí veurem què vol dir, com es comprova (mirant i amb un test) i quan cal preocupar-se’n. Spoiler: amb grups grans, gairebé mai. No cal entendre el codi (és plegat): n’hi ha prou de llegir el text i mirar els gràfics.

1. Què vol dir que una variable és «normal»?

Una variable segueix una distribució normal quan el seu histograma té forma de campana: la majoria de valors a prop de la mitjana, cada cop menys com més ens n’allunyem, i simètrica (la mateixa forma a banda i banda). Ho vam veure a la sessió 2 (la distribució normal i el valor z).

Moltes variables reals no són normals. Per exemple, els ingressos tenen una cua cap a la dreta: la majoria de gent cobra salaris moderats i uns pocs cobren molt.

2. Per què ens importa?

El t-test i l’ANOVA calculen el p-valor suposant que les mitjanes dels grups es comporten com una distribució normal. Això passa si:

  • la variable és normal dins de cada grup, o bé
  • els grups són prou grans (com a regla pràctica, 30 casos o més per grup), encara que la variable no sigui normal. És el teorema del límit central, que vam veure a la sessió 2 (I si la població no és normal?).

Per tant, la normalitat només és un problema real quan els grups són petits.

3. Un exemple: quatre grups

Simulem els ingressos de quatre grups: dos amb una variable normal i dos amb una variable asimètrica (com els ingressos reals), i de cada tipus, un grup petit (20 persones) i un de gran (150 persones).

Codi 
dades <- tibble(
  grup = factor(c(rep("Normal, n = 20", 20), rep("Asimètrica, n = 20", 20),
                  rep("Normal, n = 150", 150), rep("Asimètrica, n = 150", 150)),
                levels = c("Normal, n = 20", "Asimètrica, n = 20",
                           "Normal, n = 150", "Asimètrica, n = 150")),
  ingressos = c(rnorm(20, mean = 1500, sd = 300),
                rgamma(20, shape = 2, scale = 750),
                rnorm(150, mean = 1500, sd = 300),
                rgamma(150, shape = 2, scale = 750))
)

dades |>
  group_by(grup) |>
  summarise(n = n(),
            mitjana = mean(ingressos),
            mediana = median(ingressos))
# A tibble: 4 × 4
  grup                    n mitjana mediana
  <fct>               <int>   <dbl>   <dbl>
1 Normal, n = 20         20   1425.   1341.
2 Asimètrica, n = 20     20   1594.   1132.
3 Normal, n = 150       150   1525.   1518.
4 Asimètrica, n = 150   150   1681.   1436.

Als grups asimètrics, la mitjana és més alta que la mediana: hi ha una cua a la dreta que estira la mitjana amunt (ho vam veure a la sessió 2).

4. Primer, mirar: l’histograma

La primera comprovació, i la més útil, és dibuixar la variable. Hi afegim, en línia, la campana normal que «tocaria» amb la mateixa mitjana i desviació típica:

Codi 
corbes <- dades |>
  group_by(grup) |>
  reframe(x = seq(min(ingressos), max(ingressos), length.out = 200),
          densitat = dnorm(x, mean(ingressos), sd(ingressos)))

ggplot(dades, aes(x = ingressos)) +
  geom_histogram(aes(y = after_stat(density)), bins = 20,
                 fill = bordeus_clar, color = "white") +
  geom_line(data = corbes, aes(x = x, y = densitat), color = bordeus, linewidth = 1) +
  facet_wrap(~ grup, scales = "free") +
  labs(title = "Histogrames dels quatre grups",
       subtitle = "Línia: la distribució normal amb la mateixa mitjana i desviació típica",
       x = "Ingressos mensuals (€)", y = "Densitat") +
  theme_minimal()
  • Amb 150 casos, es veu clar: el grup normal segueix la campana i l’asimètric té la cua a la dreta.
  • Amb 20 casos, costa molt més de dir: amb tan poques dades, fins i tot una variable normal fa un histograma «estrany».

5. Mirar millor: el QQ-plot

El QQ-plot (quantile-quantile plot) és un gràfic pensat només per comprovar la normalitat. Ordena els valors de la variable i els compara amb els que esperaríem si fos normal:

  • Si la variable és normal, els punts queden sobre la línia diagonal.
  • Si els punts fan una corba o se separen de la línia als extrems, la variable no és normal.
Codi 
ggplot(dades, aes(sample = ingressos)) +
  stat_qq(color = bordeus_clar) +
  stat_qq_line(color = bordeus, linewidth = 1) +
  facet_wrap(~ grup, scales = "free") +
  labs(title = "QQ-plot dels quatre grups",
       x = "Valors esperats si fos normal", y = "Valors observats") +
  theme_minimal()

Als grups normals, els punts segueixen la línia. Als asimètrics, fan una corba: a la dreta, els valors observats són més alts del que tocaria (la cua llarga dels ingressos alts).

A R, el QQ-plot es fa amb ggplot2: ggplot(dades, aes(sample = variable)) + stat_qq() + stat_qq_line().

6. Un test: Shapiro-Wilk

També hi ha tests de normalitat. El més habitual és el de Shapiro-Wilk (shapiro.test()):

  • \(H_0\): la variable és normal
  • \(H_1\): la variable no és normal

Compte, que aquí ens interessa no rebutjar \(H_0\): si p > 0,05, no tenim evidència que la variable no sigui normal.

Codi 
dades |>
  group_by(grup) |>
  summarise(n = n(),
            p_valor = shapiro.test(ingressos)$p.value)
# A tibble: 4 × 3
  grup                    n     p_valor
  <fct>               <int>       <dbl>
1 Normal, n = 20         20 0.224      
2 Asimètrica, n = 20     20 0.0000835  
3 Normal, n = 150       150 0.457      
4 Asimètrica, n = 150   150 0.000000934

En aquest exemple, el test encerta als quatre grups: als dos normals, p > 0,05 (no rebutgem la normalitat); als dos asimètrics, p < 0,05 (rebutgem la normalitat). Però no sempre és tan fàcil.

AlertaEls tests de normalitat tenen trampa
  • Amb grups petits, el test té poca potència: sovint no detecta que la variable no és normal (just quan més ens importaria).
  • Amb grups grans, detecta desviacions minúscules i rebutja la normalitat… just quan no ens importa, perquè el teorema del límit central ja ens protegeix.

Per això, el més recomanable és mirar els gràfics (histograma i QQ-plot) i tenir en compte la mida dels grups, més que no pas fiar-se només del p-valor de Shapiro-Wilk.

7. Amb les dades de la pràctica

A la pràctica hem comparat la nota de matemàtiques dels centres públics i privats amb un t-test. Es complia el supòsit?

Codi 
ggplot(competencies, aes(x = nota_mat)) +

  facet_wrap(~ titularitat) +

       x = "Puntuació de matemàtiques (0-100)", y = "Nombre d'alumnes") +

Codi 
competencies |>
  group_by(titularitat) |>

La nota de matemàtiques no és normal: té una cua cap a l’esquerra (una minoria d’alumnes amb notes molt baixes) i Shapiro-Wilk ho confirma (p < 0,05). Però els grups són grans (163 i 317 alumnes): pel teorema del límit central, el t-test és fiable igualment.

8. I si els grups són petits i la variable no és normal?

Llavors hi ha alternatives que no suposen normalitat: els tests no paramètrics, que en lloc de comparar mitjanes comparen la posició dels valors un cop ordenats.

En lloc de… Test no paramètric A R
t-test (2 grups) Mann-Whitney (o Wilcoxon) wilcox.test(x ~ grup, data = dades)
ANOVA (3 o més grups) Kruskal-Wallis kruskal.test(x ~ grup, data = dades)

Es llegeixen igual: si p < 0,05, hi ha diferències significatives entre grups.

Grans (30 o més per grup) Tant és t-test o ANOVA, sense por
Petits Sí (els gràfics no mostren res estrany) t-test o ANOVA
Petits No (asimetria clara o valors extrems) Test no paramètric: wilcox.test() o kruskal.test()

## 6. Un test: Shapiro-Wilk

També hi ha **tests** de normalitat. El més habitual és el de **Shapiro-Wilk** (`shapiro.test()`):

- $H_0$: la variable **és** normal
- $H_1$: la variable **no** és normal

Compte, que aquí ens interessa **no** rebutjar $H_0$: si p > 0,05, no tenim evidència que la variable no sigui normal.

```{r}
dades |>
  group_by(grup) |>
  summarise(n = n(),
            p_valor = shapiro.test(ingressos)$p.value)
```

En aquest exemple, el test encerta als quatre grups: als dos normals, p > 0,05 (no rebutgem la normalitat); als dos asimètrics, p < 0,05 (rebutgem la normalitat). Però no sempre és tan fàcil.

::: {.callout-warning}
## Els tests de normalitat tenen trampa
- Amb grups **petits**, el test té poca potència: sovint **no detecta** que la variable no és normal (just quan més ens importaria).
- Amb grups **grans**, detecta desviacions **minúscules** i rebutja la normalitat... just quan **no ens importa**, perquè el teorema del límit central ja ens protegeix.

Per això, el més recomanable és **mirar els gràfics** (histograma i QQ-plot) i tenir en compte la **mida dels grups**, més que no pas fiar-se només del p-valor de Shapiro-Wilk.
:::
